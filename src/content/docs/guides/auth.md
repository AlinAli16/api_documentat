### Как авторизоваться в API
Все операции взаимодействия с эндпоинтами пользователей требуют обязательной авторизации. 
Запросы без валидного ключа отклоняются сервером с ошибкой `401 Unauthorized`.

### Где взять токен
1. Авторизуйтесь на портале разработчиков.
2. Получите токен на почту.
3. Нажмите на кнопку **Authorize** и внесите токен в появившемся окне.
4. Нажмите кнопку **Authorize**.
