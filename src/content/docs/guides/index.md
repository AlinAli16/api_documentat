### Описание API
Данное API предоставляет программный интерфейс для управления учетными записями пользователей (User). Оно создано для разработчиков, которым необходимо интегрировать централизованную систему аутентификации, регистрации и ведения клиентской базы в свои веб-сервисы или мобильные приложения.

### Основные возможности
Интерфейс спроектирован по стандартам REST и позволяет выполнять полный цикл операций с данными:
* **Регистрация:** быстрая отправка данных для создания новых профилей.
* **Чтение данных:** получение как общего списка пользователей, так и детальной информации по конкретному ID.
